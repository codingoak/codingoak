# Daniel Eicher ![](https://komarev.com/ghpvc/?username=codingoak&color=blue)

👋 Hi, I'm Daniel, a software engineer at [Ostendis](https://www.ostendis.com/).

Before I got into software, I worked as an electrician for over ten years. I built and tested data networks, installed building automation and safety systems and did final inspections as a certified electrical safety advisor. So I like to understand systems from the cable up to the code.

🌱 Right now I'm working towards a Professional Bachelor in Computer Science, specializing in Cyber Security and Computer Networks, and learning Go. I'm especially interested in where infrastructure, software and security meet, like DevSecOps and the security of OT systems.

🔧 Currently working on [meterbridge](https://github.com/codingoak/meterbridge), a read-only Modbus TCP gateway for energy meters and my first Go project.
